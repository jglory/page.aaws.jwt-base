# 응답

### 1. 200 OK

성공

#### Header

| 파라미터         | 필수 여부 | 값                | 설명           |
| ------------ | ----- | ---------------- | ------------ |
| Content-Type | O     | application/json | content type |

#### Body

json

| 파라미터1  | 파라미터2   | 파라미터3 | 자료형    | 크기   | 필수 여부 | 설명                        |
| ------ | ------- | ----- | ------ | ---- | ----- | ------------------------- |
| result |         |       | int    | 8    | O     | 결과 코드. <br>양수: 성공, 음수: 실패 |
| data   |         |       | object |      | O     | 결과 정보                     |
|        | message |       | string | 1000 | O     | 결과 메세지                    |


예시
```json
{
	"result": 1,
	"data": {
		"message": "로그인에 성공하였습니다."
	}
}
```
