# 응답

### 1. 200 OK

성공

#### Header

| 파라미터         | 필수 여부 | 값                | 설명           |
| ------------ | ----- | ---------------- | ------------ |
| Content-Type | O     | application/json | content type |

#### Body

json

| 파라미터1   | 파라미터2 | 파라미터3 | 자료형    | 크기   | 필수 여부 | 설명                      |
| ------- | ----- | ----- | ------ | ---- | ----- | ----------------------- |
| result  |       |       | int    | 8    | O     | 결과 코드<br>양수: 성공, 음수: 실패 |
| message |       |       | string | 1000 | X     | 결과 메세지                  |
| data    |       |       | object |      | O     | 상품 정보                   |
|         | id    |       | uint   | 64   | O     | 상품 정보 아이디               |
|         | name  |       | string | 1000 | O     | 상품 이름                   |
|         | price |       | uint   | 32   | O     | 상품 가격                   |

예시
```json
{
	"result": 1004,
	"data": {
		"id": 0,
		"name": "연필",
		"price": 100
	}
}
```

#### Body

| ------- | ----- | ----- | ------ | ---- | ----- | ----------------------- |
| result  |       |       | int    |      | O     | 결과 코드<br>양수: 성공, 음수: 실패 |
| message |       |       | string | 1000 | X     | 결과 메세지                  |


예시

}
