JavaDoc은 Java 소스 코드에 포함된 주석을 기반으로 API 문서를 자동으로 생성해주는 도구입니다. JavaDoc은 Java Development Kit (JDK)에 포함되어 있으며, 개발자가 작성한 코드의 클래스, 메서드, 필드 등의 구조와 설명을 명확하게 문서화하는 데 사용됩니다.

Javadoc의 사용법을 살펴보기전에 실제 Javadoc으로 생성된 문서를 한번 살펴보는 것을 추천합니다.

[https://docs.oracle.com/javase/8/docs/api/](https://docs.oracle.com/javase/8/docs/api/)
<br>


1. **클래스 주석**:
   ```java
   /**
    * 클래스에 대한 설명
    */
   public class MyClass {
       // 클래스 내용
   }
   ```

2. **메서드 주석**:
   ```java
   /**
    * 메서드에 대한 설명
    *
    * @param param1 파라미터 1에 대한 설명
    * @param param2 파라미터 2에 대한 설명
    * @return 반환값에 대한 설명
    */
   public ReturnType myMethod(Type param1, Type param2) {
       // 메서드 내용
   }
   ```


3. **필드 주석**:
   ```java
   /**
    * 필드에 대한 설명
    */
   private Type myField;
   ```


##### 사례1

```java
/**  
 * 사용자 인증 정보  
 */  
@AllArgsConstructor  
@NoArgsConstructor  
@Getter  
@Setter  
@ToString  
@EqualsAndHashCode  
@SuperBuilder  
public class UserCredentialDto {  
    /**  
     * 사용자 이메일  
     */  
    @ApiModelProperty(notes = "사용자 이메일", example = "아무개", required = true)  
    private String email;  
    /**  
     * 사용자 암호  
     */  
    @ApiModelProperty(notes = "사용자 암호", example = "12345!", required = true)  
    private String password;  
}
```

##### 사례2

```java
/**  
 * 사용자 서비스 인터페이스  
 */  
public interface UserService {  
    /**  
     * 사용자 인증 정보({@link UserCredentialDto})와 일치하는 사용자 정보({@link UserDto})를 돌려준다.  
     *     
     * @param credential 사용자 인증 정보({@link UserCredentialDto})  
     * @return <b>{@link UserDto}</b> 사용자 정보를 찾을 수 없을 경우 null 값을 돌려준다.  
     */
     public UserDto getUserByUserCredential(UserCredentialDto credential);
     
    /**  
     * 사용자 인증 정보({@link UserCredentialDto})와 일치하는 사용자 정보({@link UserDto})의 존재 여부를 돌려준다.  
     *     
     * @param credential 사용자 인증 정보({@link UserCredentialDto})  
     * @return <b>boolean</b> 사용자 정보 존재 여부. 사용자 정보를 찾을 수 없을 경우 false 값을 돌려준다.  
     */
     public boolean verifyUserCredential(UserCredentialDto credential);
}
```
