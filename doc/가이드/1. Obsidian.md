Obsidian은 Markdown 기반의 노트 및 지식 관리 애플리케이션으로, 생각과 정보를 체계적으로 정리하고 연결할 수 있는 도구입니다. 기본 Markdown 기술 이외에 다양한 플러그인을 지원하여 필요 용도에 따라 기능을 확장할 수 있습니다. 

## 설치

Obsidian(https://obsidian.md) 사이트에서 설치 파일을 다운 받으시고 설치합니다.

## 설정

1. Obsidian 프로그램을 실행합니다.
2. '보관소 폴더 열기' 항목에 있는 '열기' 버튼을 클릭합니다.
3. 팝업된 창에서 마크다운 파일의 폴더를 찾아 선택합니다.
4. '열기' 버튼을 클릭합니다.

## 사용

##### 읽기 모드 / 쓰기 모드

obsidian 의 글이 표현이 되는 메인 화면은 '읽기'와 '쓰기'의 2가지 모드가 있습니다. 문서를 작성할 때는 쓰기 모드, 문서를 읽을 때는 읽기 모드를 사용합니다.

- 다음 화면처럼 화면 상단 오른쪽의 빨간 원 안의 아이콘이 책 모양 아이콘 일 경우 쓰기 모드, 펜 모양 아이콘 일 경우 읽기 모드 입니다.

##### 다이어그램 추가

다음처럼 코드 블럭을 추가하고 코드 블럭 시작 기호 옆에 plantuml 이라고 명기하여 줍니다. 

![[../_files/Pasted image 20240926162544.png|800]]

코드 블럭 사이에 작성하고자 하는 다이어그램을 plantuml 언어로 기술하여 줍니다. 다음은 간단한 클래스 구조 다이어그램의 코드와 생성된 다이어그램의 예시입니다.

![[../_files/Pasted image 20240926163315.png]]


```plantuml
set namespaceSeparator none
skinparam linetype ortho

abstract class AbstractList
abstract AbstractCollection
interface List
interface Collection

List <|-- AbstractList
Collection <|-- AbstractCollection

Collection <|- List
AbstractCollection <|- AbstractList
AbstractList <|.. ArrayList

class ArrayList {
  Object[] elementData
  size()
}

enum TimeUnit {
  DAYS
  HOURS
  MINUTES
}

annotation SuppressWarnings


class Student {
  Name
}
Student "0..*" <- "1..*" Course
(Student, Course) <|.. Enrollment

class Enrollment {
  drop()
  cancel()
}
```
