[API(Application Programming Interface)](https://en.wikipedia.org/wiki/API) 명세서는 개발자들이 소프트웨어 컴포넌트나 서비스를 사용할 수 있도록 필요한 정보를 제공하는 문서입니다. API 명세서는 API가 어떻게 작동하는지, 어떤 기능을 제공하는지, 그리고 그 기능들을 어떻게 사용해야 하는지에 대한 상세한 지침을 포함합니다.

API 명세서는 일반적으로 다음과 같은 정보를 포함합니다:

1. 개요: API의 목적, 기능, 사용 사례 등에 대한 간략한 설명을 제공합니다.
    
2. 인증: API를 사용하기 위해 필요한 인증 방식(예: API 키, OAuth 토큰 등)에 대한 설명을 포함합니다.
    
3. 요청 형식: API에 요청을 보낼 때 사용해야 하는 [HTTP 메소드(GET, POST, PUT, DELETE 등)](https://developer.mozilla.org/en-US/docs/Web/HTTP/Methods), URL 구조, 필요한 헤더, 요청 본문의 형식(JSON, XML 등)에 대한 정보를 제공합니다.
    
4. 응답 형식: API로부터 받을 수 있는 응답의 형식과 구조, 응답 코드(200 OK, 404 Not Found 등)와 그 의미에 대한 설명을 포함합니다.
    
5. 오류 코드: API 사용 중 발생할 수 있는 오류와 그 오류 코드에 대한 설명을 제공합니다.
    
6. 엔드포인트: API가 제공하는 각각의 엔드포인트에 대한 상세한 설명을 포함합니다. 각 엔드포인트는 특정 기능을 수행하며, 그에 대한 파라미터, 요청 예시, 응답 예시 등을 포함할 수 있습니다.
    
7. 샘플 코드: API를 사용하는 방법을 보여주는 샘플 코드나 SDK(Software Development Kit)를 포함할 수 있습니다.
    

API 명세서는 개발자가 API를 빠르고 정확하게 이해하고 효율적으로 통합할 수 있도록 돕는 중요한 자료입니다. 좋은 API 문서는 사용하기 쉽고, 명확하며, 충분한 정보를 제공해야 합니다. 현대의 API 명세서는 종종 [Swagger](https://swagger.io/)나 [OpenAPI](https://www.openapis.org/)와  같은 표준화 된 포맷을 사용하여 자동으로 생성되고, 대화형 문서를 제공하기도 합니다.

### 작성

- 본 문서는 단일 API를 대상으로 작성합니다.
- 문서의 위치와 이름은 다음 규칙을 따르도록 합니다.
```
{{문서 폴더 루트}}/B 설계/B 애플리케이션 설계/D API 명세서/{{업무 구분}}/.../{{업무 구분}}/{{문서 코드}} {{이름}}
```

| 문서 폴더        | 업무 구분   | 서비스 코드 | 문서 번호  | 이름  |
| ------------ | ------- | ------ | ------ | --- |
| abc/dev-docs | 주문/대형제휴 | ABC    | 000001 | 주문  |
일 경우 문서의 위치는 다음과 같습니다. 
```
abc/dev-docs/B 설계/B 애플리케이션 설계/D API 명세서/주문/대형제휴/ABC-BBD-000001 주문
```
<br>

1. 문서 정보
- '문서 코드' 항목은 부가적인 정보를 제외한 문서 코드 만을 기입하여 주십시오.
- '관련문서' 항목은 해당 문서 열람 시 병행하여 비교 열람하기를 권장하는 문서의 목록입니다. [[BCB. 테이블 정의서 (Table Definition)#산출물 양식|산출물 양식]]을 참고하여 기입하여 주십시오.
- '업무 구분' 항목은 API를 속한 업무 영역을 구분하는 값입니다. 예를 들어 회원 관련 API 라면, '회원' 또는 회원 관련 업무 영역을 의미할 수 있는 이름을 기입하도록 의도 되었습니다.
- '업무 구분' 항목에 유효한 값에 따라 "B 설계 > B 애플리케이션 설계 > D API 명세서" 하부의 폴더 구조를 구성하여 주십시오.
- '이름' 항목은 기술하고자 하는 API의 이름을 기입하여 주십시오.
- '설명' 항목은 기술하고자 하는 API의 설명을 기입하여 주십시오.
- '태그' 항목은 특정 주제로 문서를 묶어주기 위하여 적어주는 정보입니다. [[BBD. API 명세서 (API Specification)#산출물 양식|산출물 양식]]을 참고하여 기입하여 주십시오.

<br>

2. 요청

- '호출 정보' 항목은 호출의 대상이 되는 도메인과 주소 등의 정보를 기입하여 주십시오.
```
- 도메인 : 도메인 정보
- 메소드 : http method 정보
- 호출 주소 : 항목은 호출의 대상이 되는 주소를 다음의 형식으로 기입하여 주십시오. 

    {{protocol}}://{{domain}}/{{path}}/{{path 파라미터}}/{{path}}?{{query 파라미터}}={{query 입력값}}
    
    - protocol: 프로토콜 정보
    - host : 호스트 정보
    - port : 포트 정보
    - path : 경로 정보
    - path 파라미터 : 경로 파라미터. 경로의 일부로 전달되는 데이터 값
    - query 파라미터 : 쿼리 파라미터. querystring의 형식으로 전달되는 데이터 값의 이름.
    - query 입력값 : 쿼리 입력값. querystring의 형식으로 전달되는 데이터 값  
```

- 'Path 파라미터' 항목은 경로 파라미터로 전달되는 값들의 자세한 형식을 기술하여 주십시오.
```
- 파라미터 : 파라미터 이름
- 자료형 : 자료형. '자료형과 크기' 항목 참조
- 크기: 크기. '자료형과 크기' 항목 참조
- 필수 여부 : 필수 여부. O/X
- 설명 : 파라미터 입력값에 대한 설명. 형식, 유효한 값의 범위 등의 정보를 기술하여 주세요.
```

- 'Query 파라미터' 항목은 querystring 형태로 전달되는 값들의 자세한 형식을 기술하여 주십시오.
```
- 파라미터 : 파라미터 이름
- 자료형 : 자료형. '자료형과 크기' 항목 참조
- 크기: 크기. '자료형과 크기' 항목 참조
- 필수 여부 : 필수 여부. O/X
- 설명 : 파라미터 입력값에 대한 설명. 형식, 유효한 값의 범위 등의 정보를 기술하여 주세요.
```

- 'Header' 항목은 요청 시 전달되는 Header 값들의 자세한 형식을 기술하여 주십시오.
```
- 파라미터 : 파라미터 이름
- 필수 여부 : 필수 여부. O/X
- 설명 : 파라미터 입력값에 대한 설명. 형식, 유효한 값의 범위 등의 정보를 기술하여 주세요.
```

- 'Body' 항목은 요청 시 전달되는 본문의 값들의 자세한 형식을 기술하여 주십시오.
```
형식 : 전송되는 데이터의 형식에 대한 기술. form-data / x-www-form-urlencoded / json

1. form-data 의 경우
  - 파라미터 : 파라미터 이름
  - 자료형 : 자료형. '자료형과 크기' 항목 참조
  - 크기: 크기. '자료형과 크기' 항목 참조
  - 필수 여부 : 필수 여부. O/X
  - 설명 : 파라미터 입력값에 대한 설명. 형식, 유효한 값의 범위 등의 정보를 기술하여 주세요.

2. x-www-form-urlencoded 의 경우
  - 파라미터 : 파라미터 이름
  - 자료형 : 자료형. '자료형과 크기' 항목 참조
  - 크기: 크기. '자료형과 크기' 항목 참조
  - 필수 여부 : 필수 여부. O/X
  - 설명 : 파라미터 입력값에 대한 설명. 형식, 유효한 값의 범위 등의 정보를 기술하여 주세요.

3. json 의 경우
  - 파라미터1..N : 파라미터 이름. json의 계층에 따라 컬럼 들여쓰기를 통해 표기
  - 타입 : 타입. boolean / number / string / object / array
  - 자료형 : 자료형. '자료형과 크기' 항목 참조
  - 크기: 크기. '자료형과 크기' 항목 참조
  - 필수 여부 : 필수 여부. O/X
  - 설명 : 파라미터 입력값에 대한 설명. 형식, 유효한 값의 범위 등의 정보를 기술하여 주세요.
```

3. 응답

- 'Header' 항목은 응답 시 전달되는 Header 값들의 자세한 형식을 기술하여 주십시오.

```
- 파라미터 : 파라미터 이름
- 필수 여부 : 필수 여부. O/X
- 설명 : 파라미터 입력값에 대한 설명. 형식, 유효한 값의 범위 등의 정보를 기술하여 주세요.
```

- 'Body' 항목은 응답 시 전달되는 본문의 값들의 자세한 형식을 기술하여 주십시오.
```
형식 : 전송되는 데이터의 형식에 대한 기술. text / json

2. json 의 경우
  - 파라미터1..N : 파라미터 이름. json의 계층에 따라 컬럼 들여쓰기를 통해 표기
  - 자료형 : 자료형. '자료형과 크기' 항목 참조
  - 크기: 크기. '자료형과 크기' 항목 참조
  - 필수 여부 : 필수 여부. O/X
  - 설명 : 파라미터 입력값에 대한 설명. 형식, 유효한 값의 범위 등의 정보를 기술하여 주세요.
```

4. 자료형과 크기

| 자료형     | 설명                                  | 크기         |
| ------- | ----------------------------------- | ---------- |
| boolean | 참(true) 또는 거짓(false) 값을 표현하는 논리 자료형 |            |
| int     | 정수                                  | 8/16/32/64 |
| uint    | 부호 없는 정수                            | 8/16/32/64 |
| float   | 실수                                  | 32/64      |
| decimal | 고정 소수점 실수                           |            |
| string  | 문자열                                 |            |
| object  | 객체                                  |            |
| array   | 배열                                  |            |
