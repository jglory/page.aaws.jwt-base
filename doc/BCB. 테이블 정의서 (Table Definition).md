테이블 정의서 (Table Definition)는 데이터베이스 내의 개별 테이블에 대한 구조와 규칙을 정의한 문서입니다. 이 문서는 데이터베이스 설계자, 개발자, 데이터베이스 관리자(DBA) 등이 데이터베이스를 구축하고 관리하는 데 필요한 상세 정보를 제공합니다.

테이블 정의서는 일반적으로 다음과 같은 정보를 포함합니다:

1. 테이블 이름: 테이블의 고유한 이름을 명시합니다.
    
2. 컬럼(필드) 정의:
    
    - 컬럼 이름: 각 컬럼의 이름을 명시합니다.
    - 데이터 타입: 각 컬럼에 저장될 데이터의 유형(예: INT, VARCHAR, DATE 등)을 정의합니다.
    - 길이: 데이터 타입이 가변 길이를 허용하는 경우, 최대 길이를 명시합니다.
    - NULL 허용 여부: 해당 컬럼이 NULL 값을 허용하는지 여부를 명시합니다.
    - 기본값: 컬럼에 기본값이 설정되어 있는 경우, 그 값을 명시합니다.
    
3. 기본 키(Primary Key): 테이블 내에서 각 행(row)을 고유하게 식별하는 컬럼 또는 컬럼의 조합을 정의합니다.
    
4. 외래 키(Foreign Key): 다른 테이블의 기본 키를 참조하는 컬럼을 명시하여 두 테이블 간의 관계를 정의합니다.
    
5. 인덱스(Indexes): 검색 성능을 향상시키기 위해 설정된 인덱스에 대한 정보를 포함합니다. 인덱스의 이름과 구성 컬럼을 명시합니다.
    
6. 제약 조건(Constraints): 데이터 무결성을 유지하기 위한 규칙을 정의합니다. 예를 들어, UNIQUE, CHECK, NOT NULL 등의 제약 조건이 있습니다.
    
7. 테이블 설명: 테이블의 목적, 사용 방법, 관련 비즈니스 규칙 등에 대한 설명을 포함할 수 있습니다.
    
8. 관련 문서: 테이블과 관련된 다른 문서나 참조 자료의 링크를 제공할 수 있습니다.
    

테이블 정의서는 데이터베이스의 설계 및 구현 단계에서 중요한 역할을 하며, 시스템의 유지보수와 문서화에도 필수적인 요소입니다. 이 문서를 통해 개발자와 DBA는 데이터베이스의 구조를 명확히 이해하고, 데이터의 일관성과 정확성을 유지하는 데 필요한 정보를 얻을 수 있습니다.

### 작성
- 본 문서는 기술하고자 하는 데이터베이스 인스턴스 내의 개개의 테이블을 기준으로 작성합니다. 
- 문서의 위치와 이름은 다음 규칙을 따르도록 합니다.
```
{{문서 폴더}}/B 설계/C 데이터 설계/B 테이블 정의서/{{데이터베이스명}}/{{문서 코드}} {{테이블명}}
```

| 문서 폴더        | 서비스 코드 | 구분 번호  | 데이터베이스명 | 테이블명   |
| ------------ | ------ | ------ | ------- | ------ |
| abc/dev-docs | ABC    | 000001 | ABC-DB  | T_USER |
일 경우 문서의 위치는 다음과 같습니다. 
```
abc/dev-docs/B 설계/C 데이터 설계/B 테이블 정의서/ABC-DB/IMA-BCB-000001 T_USER
```
<br>

1. 문서 정보
	- '문서 코드' 항목은 부가적인 정보를 제외한 문서 코드 만을 기입하여 주십시오.
	- '관련문서' 항목은 해당 문서 열람 시 병행하여 비교 열람하기를 권장하는 문서의 목록입니다. [[BBD. API 명세서 (API Specification)#산출물 양식|산출물 양식]]을 참고하여 기입하여 주십시오.
	- '테이블' 항목은 기술하고자 하는 테이블의 이름을 기입하여 주십시오.
	- '설명' 항목은 기술하고자 하는 테이블의 설명을 기입하여 주십시오.
	- '태그' 항목은 특정 주제로 문서를 묶어주기 위하여 적어주는 정보입니다. [[BCB. 테이블 정의서 (Table Definition)#산출물 양식|산출물 양식]]을 참고하여 기입하여 주십시오.
<br>
2. 본문
	- 상세한 테이블 스키마 정보를 기술하여 줍니다. [[BCB. 테이블 정의서 (Table Definition)#산출물 양식|산출물 양식]]을 참고하여 기입하여 주십시오.
